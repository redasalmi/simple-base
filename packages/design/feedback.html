Production contract for Data display

Purpose & anatomy

Metric, table, list, and timeline examples for structured read-only information.

States

Data regions define loading, empty, populated, stale, and error; sortable columns add sort state.

Keyboard

Native reading order is primary; sortable headers are buttons; rows are not focusable unless actionable.

Accessibility

Use table semantics for tabular relationships and captions or labelled regions for context.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Markup owns data relationships; CSS owns density; consumers own sorting, pagination, and freshness.

Resilience

Handle zero and thousands of rows, large numbers, localized formats, long values, and horizontal overflow.

Production contract for Feedback

Purpose & anatomy

Inline alert, empty state, spinner, and skeleton patterns for system response.

States

Define loading, empty, success, warning, error, and retry; never show skeleton and error simultaneously.

Keyboard

Retry and recovery actions are keyboard buttons; status itself receives no unnecessary focus.

Accessibility

Use status for polite updates, alert for urgent errors, aria-busy on loading regions, and descriptive text.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Consumers choose state and message; CSS owns visual severity; timers belong to behavior.

Resilience

Support offline, timeout, partial failure, reduced motion, long messages, and repeated retries.

Production contract for Badge

Purpose & anatomy

Short status or category label with optional leading icon.

States

Default, success, warning, error, info, and selected only when the badge is interactive.

Keyboard

Static badges are not focusable; interactive filters must use button semantics.

Accessibility

Resilience

Production contract for AlertDialog

Purpose & anatomy

Trigger-owned modal with title, consequence, safe action, destructive action, and description.

States

Closed, opening, open, submitting, failure, and closed/restored states are required.

Keyboard

Opening focuses title or safest action; Tab is trapped; Escape cancels when safe; closing restores trigger focus.

Accessibility

Use native dialog or ARIA alertdialog with labelled title and description; background becomes inert.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns portal, modal isolation, focus trap, dismissal, and restoration; CSS owns surface and states.

Resilience

Handle long consequences, async failure without closing, zoom, reduced motion, and destructive-action latency.

Production contract for Toast

Purpose & anatomy

Transient status with message, optional action, close control, and bounded lifetime.

States

Entering, visible, paused, action-pending, exiting, and stacked states are required.

Keyboard

Toast does not steal focus; action and close are tabbable; Escape dismissal follows the application policy.

Accessibility

Announce success politely and errors assertively only when urgent; preserve action labels.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns queue, timing, pause, and dismissal; CSS owns stack and motion.

Resilience

Pause on hover/focus, support reduced motion, long translations, duplicate events, and viewport edges.

Production contract for Progress

Purpose & anatomy

Label, current value, track, indicator, and optional supporting status.

Production contract for Avatar

Purpose & anatomy

Image or initials fallback with accessible identity context and optional status.

States

Loading, image loaded, fallback, broken image, and optional presence states are required.

Keyboard

Static avatars are not focusable; linked profile avatars use link semantics and a name.

Accessibility

Decorative repeated avatars use empty alt; identity-bearing images expose the person or entity name.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Consumers own image/fallback selection; CSS owns size, crop, and status placement.

Resilience

Handle missing images, long initials, Unicode names, slow loading, high density, and group overflow.
