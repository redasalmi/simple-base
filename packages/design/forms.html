Production contract for Forms

Purpose & anatomy

Label, control, help text, validation message, input group, and upload composition.

States

Fields define default, focus, filled, invalid, disabled, and read-only; async submission adds busy and success.

Keyboard

Follow native field order; Enter submits only within a form; errors receive focus or a summary link after submit.

Accessibility

Associate every message with aria-describedby and set aria-invalid only while invalid.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

HTML owns validation semantics; CSS owns states; application code owns submission and server errors.

Resilience

Preserve input after errors; support autofill, long labels, RTL, zoom, and offline retry.

Production contract for Button

Purpose & anatomy

Native button with text or accessible icon, optional leading/trailing icon, and priority variant.

States

Default, hover, focus-visible, active, disabled, and busy are required; success/error belong to surrounding feedback.

Keyboard

Enter and Space activate; busy or disabled buttons cannot submit twice.

Accessibility

Use button, name icon-only actions, preserve visible focus, and expose aria-busy during async work.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Browser owns activation; CSS owns visuals; application code owns side effects and busy state.

Resilience

Labels wrap or expand, touch target reaches 44px, and rapid repeated activation is guarded.

Production contract for Switch

Purpose & anatomy

Binary native checkbox or button, visible label, optional description, and current state.

States

Off, on, hover, focus-visible, disabled, and pending states are required.

Keyboard

Space toggles; Enter toggles only when implemented as button; prevent duplicate remote updates.

Accessibility

Expose role=switch and aria-checked when native checkbox semantics are not retained.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns persisted state; CSS only reflects checked/disabled/pending attributes.

Resilience

Label the consequence, preserve state on failure, support touch, RTL, and reduced motion.

Resilience
