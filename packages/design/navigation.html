Production contract for Navigation

Purpose & anatomy

Primary navigation, sidebar, menu, and command-palette navigation examples.

States

Links define default, hover, focus-visible, current, and disabled/unavailable where justified.

Keyboard

Tab follows links; menus use arrow keys only when they are true application menus; Escape closes popups.

Accessibility

Use nav with an accessible name and aria-current on the active destination.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

HTML owns links and landmarks; managed behavior is limited to menus and command palettes.

Resilience

Handle long labels, narrow widths, RTL order, zoom, and routes unavailable by permission.

Production contract for Tabs

Purpose & anatomy

Tablist, tabs, and one associated tabpanel per active view.

States

Tabs define default, hover, focus-visible, selected, and disabled; panels define loading, empty, and error where data-driven.

Keyboard

Left/Right moves, Home/End jumps, and activation follows the documented automatic-selection model.

Accessibility

Each tab has role=tab, selected state, controls, and a labelled tabpanel; use roving tabindex.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns selection and focus; CSS reflects aria-selected; consumers own panel content.

Resilience

Support 1–20 tabs, overflow, long labels, RTL arrow direction, and restored selection.

Production contract for Accordion

Purpose & anatomy

Heading, native summary trigger, disclosure icon, and collapsible content region.

States

Closed, open, hover, focus-visible, and disabled-if-required are defined.

Keyboard

Enter or Space toggles summary; Tab reaches each summary; content follows normal tab order.

Accessibility

Prefer details/summary; otherwise connect button and region with expanded and controls.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Browser owns native disclosure when details is used; CSS owns indicator and surface.

Resilience

Handle long headings, nested interactive content, print, RTL, zoom, and reduced motion.

Production contract for Breadcrumbs

Purpose & anatomy

Navigation landmark containing an ordered path of links and a current-page item.

States

Links define default, hover, and focus; current item is text, not an active link.

Keyboard

Tab visits links in order; separators are never focusable.

Accessibility

Name the nav Breadcrumb; use ol; mark current item with aria-current=page; hide separators.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

HTML owns hierarchy; CSS owns separators and truncation.

Resilience

Collapse middle items accessibly on narrow screens and preserve full names for assistive technology.
