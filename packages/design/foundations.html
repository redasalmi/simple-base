Production contract for Typography

Purpose & anatomy

Type roles: display, six heading levels, body, caption, label, and code.

States

No interaction states. Preserve hierarchy and readable text contrast in every theme.

Keyboard

No custom keyboard behavior. Text selection and browser zoom remain native.

Accessibility

Use semantic headings in document order; never choose a heading level for appearance alone.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

CSS owns type tokens and utility classes; consuming markup owns semantic element choice.

Resilience

Allow 200% zoom, long localized headings, CJK, RTL, and 65–75ch prose.

Production contract for Layout primitives

Purpose & anatomy

Container, section, stack, grid, and sidebar compositions built from spacing tokens.

States

Layouts reflow at documented breakpoints; no hover or active state belongs to a layout primitive.

Keyboard

Accessibility

Theming

Implementation boundary

Resilience

Production contract for Component states

Purpose & anatomy

Reference matrix for default, hover, focus-visible, active, disabled, loading, and error.

States

Each row demonstrates one named state; disabled controls are actually disabled and loading is announced.

Keyboard

Focus examples remain keyboard reachable; disabled examples are skipped by native tab order.

Accessibility

Pair state color with text, icon, shape, or status; loading uses aria-live or aria-busy.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

CSS defines visuals; component behavior sets native attributes and ARIA state.

Resilience

State labels survive high contrast, reduced motion, monochrome, and every supported theme.

Production contract for Divider

Purpose & anatomy

Horizontal or vertical separator used only where spacing cannot express grouping.

States

Static only; orientation changes with composition, not interaction.

Keyboard

No keyboard behavior and no tab stop.

Accessibility

Use hr for thematic breaks or role=separator with aria-orientation when structural.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

CSS owns stroke and spacing; markup owns semantic versus decorative intent.

Resilience

Remain visible in forced colors and avoid fixed lengths that overflow.
