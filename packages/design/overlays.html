Production contract for Overlays

Purpose & anatomy

Context menu, dropdown, sheet, and modal anatomy illustrating floating-layer hierarchy.

States

Closed, opening, open, active item, disabled item, submitting, error, and closing are defined per overlay type.

Keyboard

Trigger opens; arrows navigate menus; Escape closes; Tab policy follows menu versus dialog semantics.

Accessibility

Connect triggers and layers, expose expanded state, label dialogs, and keep background inert for modals.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns portal, placement, collision, focus, and dismissal; CSS owns elevation and transitions.

Resilience

Handle viewport collision, nested scroll, zoom, RTL placement, reduced motion, and long menu labels.

Production contract for Card

Purpose & anatomy

Optional heading, body, metadata, media, and action area grouped as one conceptual object.

States

Static cards have no interaction states; linked/actionable cards add hover, focus-visible, active, disabled, and loading.

Keyboard

Never make a non-interactive card focusable; actionable cards use one primary link or button without nested controls.

Accessibility

Use article only for independently meaningful content and preserve heading order.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

CSS owns surface variants; consumers choose semantic container and interaction model.

Resilience

Handle missing media, long titles, mixed content heights, narrow containers, and zoom.

Production contract for Dialog

Purpose & anatomy

Trigger-owned modal with title, description, content, close control, and action row.

States

Closed, opening, open, submitting, inline error, and closing/restored states are required.

Keyboard

Opening places focus deliberately; Tab is trapped; Escape closes; closing restores trigger focus.

Accessibility

Use native dialog where practical or role=dialog with labelled title/description; modal background is inert.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns portal, focus trap, dismissal, and restoration; CSS owns surface and motion.

Resilience

Handle long forms, validation without closing, mobile viewport, virtual keyboard, zoom, and reduced motion.

Production contract for Popover

Purpose & anatomy

Trigger, anchored non-modal surface, optional heading, content, and actions.

States

Closed, opening, open, active control, and closing states are required.

Keyboard

Trigger toggles; Escape closes; outside click closes when safe; closing returns focus when it moved inside.

Accessibility

Expose trigger expanded/controls state and label complex popovers; do not use tooltip semantics.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns anchor, collision, dismissal, and focus policy; CSS owns surface and origin-aware motion.

Resilience

Flip or shift at viewport edges, support zoom, RTL placement, long content, and reduced motion.

Production contract for Tooltip

Purpose & anatomy

Trigger-associated brief text label with no interactive content.

States

Hidden, delayed opening, visible, and closing states are required; subsequent tooltips may skip delay.

Keyboard

Focus or hover opens; Escape closes; tooltip itself never receives focus.

Accessibility

Connect with aria-describedby and keep the trigger name meaningful without the tooltip.

Theming

Use semantic foreground, surface, border, focus, and state roles; preserve WCAG 2.2 AA across all nine themes.

Implementation boundary

Behavior owns delay and dismissal; CSS owns placement and motion; never place actions inside.

Resilience

Support touch alternatives, viewport collision, long but brief text, zoom, and reduced motion.
