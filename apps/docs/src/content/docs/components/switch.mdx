An immediate on or off preference. A native checkbox with switch semantics, named by its label like any checkbox.

<FrameworkCode code={'import { Switch } from "@simple-base/solid";'} />

## On & off

A switch applies a setting immediately. These settings only affect their local status text and reset when you leave the page.

<Example name="switch/OnAndOff" />

## In a form

A switch submits like a checkbox: its name and value while on, nothing while off. defaultChecked sets the state that Reset restores.

<Example name="switch/InForm" form />

## Disabled states

Unavailable off and on settings. Keep the label visible to explain which preference is locked.
