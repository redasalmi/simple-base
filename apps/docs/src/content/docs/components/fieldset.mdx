## Grouped fields

A legend names related controls, and the description applies to the whole group. Each control keeps its own Field for its label and messages.

<Example name="fieldset/Grouped" />

## Disabled

disabled uses the native fieldset attribute: every control inside is disabled and skipped by Tab, and the legend and description dim.
