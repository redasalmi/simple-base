## Label, description & error

The root sets id, required, and invalid once; the label, input, and messages are linked from it. Enter a full address to clear the error.

<Example name="field/DescriptionAndError" />

## States

Required, read-only, and disabled. A disabled field dims its label and description with the control.

## Text area

FieldTextArea takes the same wiring. This local example requires a note; the character count updates as you type.
