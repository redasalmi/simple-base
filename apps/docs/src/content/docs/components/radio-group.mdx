One choice from a short list, inside a Fieldset. Each option is a full-width row with a native radio, and the group shares a name and the selected value.

<FrameworkCode
  code={'import { Fieldset, RadioGroup, RadioGroupItem } from "@simple-base/solid";'}

## Controlled

value and onValueChange keep the selection in your state. Arrow keys move the selection within the group.

<Example name="radio-group/Controlled" />

## In a form

The checked radio submits its value under the group's name. defaultValue picks the initial choice that Reset restores.

<Example name="radio-group/InForm" form />

## Required with an error

required makes every radio natively required. This form sets noValidate so FieldsetError replaces the browser's message; submit without a choice to show it.

<Example name="radio-group/Required" />
