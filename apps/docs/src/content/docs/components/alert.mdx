## Statuses

Alerts support success, warning, danger, and info. The status tints the border and the mark; the title and description carry the meaning. Without a status, the alert keeps the neutral border and a danger mark.

<Example name="alert/Statuses" />

## Actions and dismissal

AlertActions holds the recovery path. AlertClose is a plain type=button control: name it with aria-label and remove the alert from your own state. Dismissing here only hides this local specimen.
