Independent choices that can be combined. A native checkbox, styled by the system and labeled by its surrounding content.

<FrameworkCode code={'import { Checkbox } from "@simple-base/solid";'} />

## Independent choices

Each option is independent. Click the label or press Space on a focused checkbox to toggle it.

<Example name="checkbox/IndependentChoices" />

## Select all

A parent checkbox shows the mixed state while only some of its options are checked. Toggling it checks or clears them all.

<Example name="checkbox/SelectAll" />

## In a form

Checked boxes submit their name and value; unchecked ones submit nothing. defaultChecked sets the initial state that Reset restores.

<Example name="checkbox/InForm" form />

## Disabled states

Both unchecked and checked disabled states are shown. Disabled controls retain their value but cannot be changed.

<Example name="checkbox/Disabled" />
