<FrameworkCode code={'import { Select, SelectTrigger, SelectItem } from "@simple-base/solid";'} />

## Choose a single option

Open the list with Enter, Space, or a click, then move with the arrow keys, Home, and End. Type a letter to jump to a matching option. Japan Standard Time is disabled in this demo, and Escape closes the list without changing the value.

<Example name="select/SingleValue" />

## In a form

With name and defaultValue the select needs no signal or handler: a hidden native select submits the option value with the form, or an empty value while nothing is selected, and Reset restores the initial selection.

<Example name="select/InForm" form />

## Empty and updated options

Open the initially empty list to see the empty message, then load a local collection and reopen it. No request is made and no data is saved.

<Example name="select/UpdatedOptions" />
