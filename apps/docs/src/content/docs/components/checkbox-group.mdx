Any number of choices from a short list, inside a Fieldset. Each option is a full-width row with a native checkbox, and the group reports the checked values as an array.

<FrameworkCode
  code={'import { Fieldset, CheckboxGroup, CheckboxGroupItem } from "@simple-base/solid";'}
/>

## Controlled

value and onValueChange hold the checked values as an array, in the order the boxes appear.

<Example name="checkbox-group/Controlled" />

## In a form

Each checked box submits its value under the group's name; unchecked boxes submit nothing. defaultValue sets the initial state that Reset restores.

<Example name="checkbox-group/InForm" form />

## Required with an error

required means at least one checked box: while none is, every box is natively required. This form sets noValidate so FieldsetError replaces the browser's message; submit without a check to show it.

<Example name="checkbox-group/Required" />
