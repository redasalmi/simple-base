Short, non-interactive labels for status and metadata. The component [Badge](/components/badge/) renders this markup for you.

```css
@import "@simple-base/css/badge";
```

## Variants

Nine variants and two sizes, set with `data-variant` and `data-size`. Success, danger, warning, and info draw a glyph, so color is never the only cue.
