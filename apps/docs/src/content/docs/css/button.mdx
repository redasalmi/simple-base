Actions with a clear order of importance. The component [Button](/components/button/) renders this markup for you.

```css
@import "@simple-base/css/button";
```

## Variants and sizes

Six variants and three sizes, set with `data-variant` and `data-size`. Disabled buttons drop their color rather than fading, and `aria-disabled="true"` looks the same as `disabled`.
