A legible type scale for interfaces. Atkinson Hyperlegible for the work, Young Serif for headings and figures. Typography stays CSS-only in every framework: these classes are the API, and there are no typography components.

```css
@import "@simple-base/css/typography";
```

## Headings

`.sb-heading-1` to `.sb-heading-3` use the Young Serif display face at a regular weight; `.sb-heading-4` to `.sb-heading-6` stay in the body face. They are sized 2.25, 1.75, 1.5, 1.25, 1.125, and 1rem. Choose the HTML heading level for structure and the class for visual size.

## Fonts

The tokens name Atkinson Hyperlegible Next, Young Serif, and Atkinson Hyperlegible Mono, with system fallbacks. The package does not download web fonts; this site loads them from Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Atkinson+Hyperlegible+Mono:wght@400;500;600&family=Atkinson+Hyperlegible+Next:wght@400;500;600;700&family=Young+Serif&display=swap"
/>
```
