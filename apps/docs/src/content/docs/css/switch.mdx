A native checkbox with switch semantics. The component [Switch](/components/switch/) renders this markup for you.

```css
@import "@simple-base/css/switch";
```

## Settings

Use `role="switch"` on a checkbox, named by its label like any checkbox. The thumb shows a check or a cross, so the state doesn't rely on color.
