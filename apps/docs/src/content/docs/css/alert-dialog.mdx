A native modal dialog that asks for confirmation before a destructive action. The component [AlertDialog](/components/alert-dialog/) renders this markup for you.

```css
@import "@simple-base/css/alert-dialog";
```

It needs the state that [AlertDialog](/components/alert-dialog/) manages, so its live example is on the component page.

## Reference

<CssReference sheet="alert-dialog" />

The content is a native `<dialog>`; `[open]` on `.sb-alert-dialog-content` shows it.
