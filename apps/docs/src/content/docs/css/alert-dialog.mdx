A native modal dialog that asks for confirmation before a destructive action. The component [AlertDialog](/components/alert-dialog/) renders this markup for you.

```css
@import "@simple-base/css/alert-dialog";
```

It needs the state that [AlertDialog](/components/alert-dialog/) manages, so its live example is on the component page.

## Reference

<CssReference sheet="alert-dialog" />

The content is a native `<dialog>`; `[open]` on `.sb-alert-dialog-content` shows it. It fades and scales in when it opens. Browsers that support the `overlay` property also animate the close; the others close it at once. While it's open, scrolling inside it or over the backdrop doesn't scroll the page, in browsers that contain scrolling on non-scrollable boxes. The footer stacks its buttons when the content box is narrower than 24rem.
