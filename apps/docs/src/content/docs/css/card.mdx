A bordered surface for related content, with its own interior padding. The component [Card](/components/card/) renders this markup for you.

```css
@import "@simple-base/css/card";
```

## Variants

The base card has a border, a surface, and a 1px baseline. `data-variant="flat"` removes them for content already on a surface, and `"rule"` keeps only a top border for stacked sections.
