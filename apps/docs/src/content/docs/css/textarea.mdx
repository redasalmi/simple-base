Multi-line text entry that resizes vertically. The component [TextArea](/components/textarea/) renders this markup for you.

```css
@import "@simple-base/css/textarea";
```

## Note

The same focus, validation, and disabled treatments as an input, with a minimum height you can change through `--sb-textarea-min-height`.
